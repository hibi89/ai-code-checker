# Code Checker v2 — Commercial Strategy (Approved Product Type; Prices and Listing Unconfirmed)

2026-10-26 KST. Offline program is owner-approved as primary target; displayed prices remain hypotheses. No actual executable, market listing or permission to claim readiness.

## Principle
Sell practical repeatable value to a nondeveloper/vibe-coding customer: portable offline software and locally generated evidence/priority reports, not just an API wrapper. Report-only service remains separately available.

## Suggested menu (prices are hypotheses, not confirmed demand)
- Self-service offline tool: **KRW 49,000 one time**. Portable Windows app, unlimited local runs, basic code-risk checks, local HTML/Markdown report and print-to-PDF.
- Assisted startup + one verified report: **KRW 99,000 one time**; scope/time and buyer data handling to be agreed before offering.
- Independent one-off verified diagnostic report: **KRW 40,000** initially, no software transfer; offered separately if buyers prefer a human-reviewed outcome.
- Optional BYOK model explanations and any premium human review are separately priced/consented, never silently charged. No subscriptions for offline core.
- If marketplace requires specific Basic/Standard/Premium package format, adapt the final validated products to platform's then-current form.

## Critical commercial caveat
Existing public repo is MIT and its CLI/source are already freely accessible and commercially reusable. Do not claim exclusive ownership of this publicly released code or that clients must pay to use the existing free CLI. Paid differentiation must be genuine packaging, stable Windows UX, clear Korean reports, curated safe rule sets, tutorials, support and optional verified human review.
If owner wants to sell proprietary software code rather than convenient support/distribution, approve a separate PRIVATE packaging/product repo and licensing plan BEFORE writing confidential new features. Private repo CI must remain within actual monthly limits (or use local builds).

## Costs
- Seller core code/scans: no mandatory paid Gemini, hosting, database or API. Existing AI/dev subscriptions, work time, platform payment fees, power, support and Windows signing remain real costs.
- Customer post-purchase basic scan: no required API tokens, cloud account, subscription or usage fees; uses own CPU/disk/electricity. No false 'guaranteed forever 0 cost' claim.
- Distributed binary can be blocked by SmartScreen/Smart App Control without signing/reputation; no blanket assurance that all customer PCs can run it.
- Rules such as Semgrep registry rules may impose commercial redistribution restrictions; review license provenance before using.

## Scope, promise and demonstration
- NO 500-line cap in software menu. Support limits based on tested total files/bytes, with coverage manifest and explicit skipped/unsupported status.
- Demonstrate a synthetic repository scan, sample report with exact file and line, safe comparison and limitations. Do not claim complete security audit.
- Product tagline candidate: '바이브코딩 프로젝트 로컬 코드 위험 진단 — 한 번 설치하고 반복 검사'.
- Pilot checks: user can unzip and run on clean Windows machine, no account/network, reports print, secure ZIP handling, realistic scan time and false positives.
- Sell only after minimum offline real-product acceptance gates, not merely CI PASS.
